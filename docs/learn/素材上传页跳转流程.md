# 素材库大文件上传：内嵌页面跳转 + 手动上传 + 刷新列表

> 结论来自 2026-08 实测：视频/音频大文件没有可用的官方开放 API（1GB 限额素材），
> 但网页端后台的上传页是现成的。方案定为——素材库弹窗里点「上传新视频/上传新音频」，
> 软件复用内嵌微信后台窗口直接跳到官方上传页，用户手动上传后回到弹窗点刷新即可取到新素材。

## 官方上传页地址

视频（视频号素材上传编辑页）：

```
/cgi-bin/appmsg?t=media/videomsg_edit&action=video_edit&type=15&isNew=1&lang=zh_CN
```

音频（音频素材库页，官方在该页提供上传入口）：

```
/cgi-bin/filepage?type=3&begin=0&count=20&lang=zh_CN
```

两个页面都需要在当前 URL 后面动态拼 `&token=<当前页 token>`，token 从后台窗口
`location.href` 的 query 里取，取不到时回退到 cookie（精确 `token` 键 → 纯数字值兜底），
不要硬编码（会过期）。

## 实现方式

- Rust：`open_material_upload_page(media_type)` 命令。
  - **快路径（默认）**：从 WebView2 CookieManager 读 `mp.weixin.qq.com` 的**整套真实会话
    cookie**（含 HttpOnly，主窗口与后台窗口共享同一份仓库），拼成 Cookie 头用 reqwest
    请求后台首页，向服务器**换取一个新鲜 token**（登录态会 302 到带 `token=` 的地址，
    或首页 HTML 内嵌），拿到后拼绝对 URL 直接 `navigate` 目标页并立即显示窗口——
    不依赖隐藏窗口先把主页加载完，也不用等页面注入。
  - 换到的 token 缓存 10 分钟，期间再点上传直接跳转，不再发会话请求。
  - **兜底**：未登录（读不到会话 cookie / 换不到 token）或快路径异常时回退页面注入流程
    `eval_backend_expr` 注入 `location.href = target`，显示窗口引导扫码登录。
  - 两条路径都返回 `{ vs_ok, target }` JSON 供前端校验。
- 结论（2026-08 实测修正）：**cookie 仓库里的 `token` 值不能直接当参数**——CookieManager
  直读（含按路径查询、非 HttpOnly 优先、有效期排序）跳转必弹登录，而用户点登录能秒进说明
  会话 cookie 有效、纯属拿旧值当参数。**正确做法是用整套会话 cookie 向服务器换新 token**
  （服务器基于当前会话签发的那串，等价于页面 URL 里的 token），这也是快路径的原理；
  页面注入只作为兜底，不再依赖它提速。
- 前端：素材库弹窗的视频/音频子页底栏各放一个上传按钮；点击后切到内嵌微信窗口上传，
  完成后回到弹窗点列表右上角刷新（复用 `loadVideoLibrary(0)` / `loadVoiceLibrary(0)`）。
- 素材列表读取走既有凭证通道（`list_video_materials` / `list_voice_materials`），
  与内嵌窗口的上传动作相互独立，所以刷新即可看到新素材。

## 踩坑记录

- `location.href = target` 的跳转在 CDP `Runtime.evaluate` 返回后才真正开始，
  不要依赖返回结果判断页面加载完成；前端只校验「跳转指令已发出」。
- 首次打开后台窗口时页面可能还没加载完，token 取到空值会跳到登录页，
  用户扫码登录后微信会自动带回正确页面，无需特殊处理；此时再点一次上传按钮即可。
- **新建窗口在 `about:blank` 上执行脚本会读不到 cookie**（SecurityError）：
  必须先等窗口 URL 落到 `https://mp.weixin.qq.com/` 再注入，脚本内读取 cookie 也要
  套 try/catch，并把「页面未就绪」作为可重试错误处理。
- 跳转全程在隐藏窗口里完成，不需要把主页显示给用户；跳转成功后等目标页开始加载
  （URL 出现 `action=video_edit` / `filepage`）再显示窗口，未登录时立即显示登录页。
- 不要迷信"cookie 持久化落盘就能直读 token"：能读到值 ≠ 微信认可该值，鉴权 token
  以服务器当前会话签发为准；cookie 仓库里的同名值只能当会话凭证用来换新 token，
  不能直接拼进目标页 URL。
- 后台窗口停在 `https://mp.weixin.qq.com/` 裸主页时 URL 里没有 token，
  必须从 cookie 取；登录态下 cookie 里有 token 值（纯数字串）。
- 快路径换 token 的请求目标：`/cgi-bin/home?t=home/index&lang=zh_CN`（已登录 302/HTML
  带 token，未登录落登录页）；兜底再取裸主页 HTML 里 SPA 内嵌的 `t: "xxxxxx"` 字段。
  注意这两个来源都必须是 6-12 位纯数字才采信（与页面内兜底规则一致）。
- 换到的 token 失效时目标页会弹登录：窗口已经显示，用户直接在里面重登即可，
  缓存会在下次点击时清除并重新换取。
- 不要试图注入上传表单或模拟文件选择（微信端有强校验），大文件交给官方页面上传。
