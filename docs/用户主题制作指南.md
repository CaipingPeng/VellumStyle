# 用户主题制作指南

VellumStyle 的主题统一为 **CSS 文件**。主题文件放在「主题文件夹」里，应用启动时自动扫描并合并显示。打开方式：主题选择器底部 →「打开主题文件夹」。

主题文件夹默认位置（Windows）：

```
%APPDATA%\com.vellumstyle.desktop\themes
```

## 制作 CSS 主题

在主题文件夹里新建一个 `.css` 文件，例如 `我的主题.css`（文件名去掉扩展名就是主题 id 和显示名），直接写样式：

```css
#article {
  font-size: 16px;
  color: #333;
  line-height: 1.8;
}

#article h1 {
  font-size: 26px;
  color: #c0392b;
  border-bottom: 2px solid #eee;
  padding-bottom: 8px;
}

#article blockquote {
  margin: 16px 0;
  padding: 8px 16px;
  background: #f8f9fa;
  border-left: 4px solid #c0392b;
}

#article pre.custom {
  background: #282c34;
  border-radius: 8px;
}
```

要点：

- **不用手动加 `#article` 前缀**：加载时所有选择器会自动作用到文章根容器。`h1 { ... }` 会被改写成 `#article h1 { ... }`，不会污染应用界面；已经写了 `#article` 前缀的也能正常识别（旧版 `#nice` / `#wechat-article` 前缀会自动归一化）。
- 支持常规 CSS：伪元素（`::before` / `::after`）、`@media`、`@supports`（内部的规则同样自动作用域）、`@keyframes`、`@font-face` 等都会原样保留。
- 预览、缩略图、复制到微信共用同一份样式，效果所见即所得。
- 保存文件后，在主题选择器里重新扫描（点「打开主题文件夹」或重启）即可看到新主题。

限制：

- 主题代码高亮由应用统一管理（`#article pre.custom` 等），CSS 主题不需要也不应覆盖高亮规则。

## 常见问题

- **主题文件放进文件夹后没出现**：检查文件名是否符合 id 规则（不能以 `.` 开头、不能包含 `..`、不能用 Windows 保留名），以及 CSS 文件是否为空。
- **用户主题与内置主题同名（同 id）**：用户主题会覆盖内置主题。想保留内置主题，请用不同的文件名。
- **分享主题**：把 `.css` 文件发给对方，对方通过主题选择器「导入主题文件」或直接放进主题文件夹即可。
