## A. 字号与排版（本次核心新功能）

### A1 全局字号

入口：**主题弹窗 → 排版主题 tab → 搜索框下方那一行「全局字号」**

- [ ] 点 `−` / `+`，数字按 **0.05** 步进
- [ ] 范围卡在 **0.80 – 1.50**，到边界后对应按钮变灰
- [ ] 调大后**整篇一起**变大：正文、各级标题、引用、表格、列表、代码块都跟着变
- [ ] **标题与正文的比例关系不变**（不会出现"只有正文变大、标题纹丝不动"）
- [ ] 点最右的「恢复默认」回到 `1.00`，按钮随即变灰
- [ ] 切到「代码主题」tab 时这一行**不出现**（它只属于排版主题）

### A2 点击预览元素按角色调字号

入口：**直接点右侧预览里的元素**（不需要先开任何开关）

- [ ] 点正文段落 → 面板标题显示「正文段落」，且**所有**段落同时出现虚线描边
- [ ] 分别点 h1 / h2 / h3 → 显示「一级标题」/「二级标题」/「三级标题」
- [ ] 点**引用块里的文字** → 显示「引用」，**不是**「正文段落」
- [ ] 点表格 → 「表格」；点代码块 → 「代码块」；点列表项 → 「列表」
- [ ] 点图片 / 视频卡片 → **不弹面板**（保留它们自己的右键菜单和拖拽缩放）
- [ ] **拖拽划选文字** 后松手 → 不弹面板
- [ ] 拖图片的缩放角 → 不弹面板
- [ ] 点文章的**空白边距** → 面板显示「全文排版」，只有「全局」一行、没有「本元素」行
- [ ] 面板里「本元素」能单独调这一类，范围 **0.60 – 2.00**，步长 0.05，到边界按钮变灰
- [ ] 「本元素」的「恢复默认」只重置**当前这一类**，其它类不受影响
- [ ] 「全部恢复默认」把这一类**和**全局一起归 1
- [ ] 点面板以外的任意位置 → 面板收起、描边消失
- [ ] 点面板右上角 `×` → 同上

### A3 叠加与持久化

- [ ] 全局与角色可**叠加**：全局 `1.20` + 段落 `1.50` → 段落明显比标题涨得多
- [ ] **完全退出应用再打开**，字号设置还在
- [ ] 换一个排版主题后，字号设置**保留**（不跟着主题重置）
- [ ] 切到另一篇文档，字号设置仍生效

### A4 面板跟随（最容易出问题，重点看）

- [ ] 调字号的瞬间预览会重排 → 面板**不会**跳到别的段落上，仍停在原来那个元素旁
- [ ] 滚动预览 → 面板跟着锚点元素走，不会飘在半空
- [ ] 面板开着时在左侧编辑正文（触发重渲染）→ 面板仍停在同类元素的同一个位置
- [ ] 关掉面板后再点另一个元素 → 能正常打开，且不残留旧描边

### A5 导出与复制（**最关键，直接影响用户**）

- [ ] 「复制到微信」→ 粘贴到微信编辑器：字号与预览**一致**
- [ ] 粘贴结果里**没有**虚线描边
- [ ] 粘贴结果里**没有** `class=""` 这类空属性
      （验证方法：在浏览器里粘贴后按 F12 看元素，或先「导出 HTML」再搜 `class=""`）
- [ ] 导出 HTML / 另存文件：同样字号正确、无描边、无空 `class`
- [ ] 导出的字号是**相对单位**（形如 `1.35em`）而不是写死的 `px`
      —— 这样在微信里换设备显示才正常。**不要**拿导出里的 `font-size` 数值直接跟预览的 px 硬比，
      两者单位不同，会误判
- [ ] 调大正文后，**代码块字号跟着放大**，不会显得比正文小一截

## B. 预览图链路（后端）

必须 `npm run tauri dev`

- [ ] 含微信图片（`mmbiz.qpic.cn` / `mmbiz.qlogo.cn`）的文章，图片能正常显示
- [ ] **完全退出应用再打开**同一篇文章，图片明显更快出现（走了磁盘缓存）
- [ ] 把网络断开（或断网卡）后打开含图文章 → 图片失败但**应用不崩**、不卡死
      （缓存是纯加速层，失败会静默降级）
- [ ] 若本机装了 Clash / v2ray 之类的代理（**配了但没启动**也算），图片仍能加载
      —— 这是本次修的 `.no_proxy()` 问题，之前会导致预览图整片挂掉
- [ ] 应用数据目录下能看到 `cache/wximg/` 并且有文件生成

## 附 2：已知边界（别误判为 bug）

- 字号只影响**本机显示**，不改动主题 CSS 文件本身 —— 换机器或重装后要重设。
- 图片、视频卡片**不参与**字号缩放，点它们也不弹面板（这是刻意的，为了保留原有交互）。
- 面板描边是**预览专用**，复制/导出时会被摘掉 —— 设计如此。
- 「全局字号」在代码主题 tab 下不显示。
- 应用里现有的 **6 个历史 CRLF 文件**（`package.json`、`tauri.conf.json`、
  `SettingsDialog.tsx`、`ThemePickerDialog.tsx`、`outboundIpMonitor.ts`、`package-lock.json`）
  行尾风格与仓库其它文件不同，属既有状态，本次未动。
